# Support

Claw (solid-octo-fiesta project) is currently in **closed testing (TestFlight)**.

## Get help / report a problem

**Primary channel:** [Open an issue in this repository](../../issues)

When reporting a problem, please include:

- Device model and iOS version
- App version/build number (visible in Settings → About)
- What you were doing (e.g., "generating a 30-min running playlist")
- What happened vs. what you expected
- Screenshots or screen recordings, if applicable

## Common topics

- **Playlist generation is slow or times out** — generation involves multiple AI calls; please include roughly how long you waited.
- **Songs missing from Apple Music** — some generated songs may not exist in your regional Apple Music catalog; reporting examples helps us improve resolution.
- **Privacy questions or deletion requests** — see [PRIVACY.md](PRIVACY.md); open an issue and we will respond.

## Response expectations

This is an indie project in active development. We read every issue and typically respond within a few days.
